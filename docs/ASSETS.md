# UI image assets

Navigation uses native Roblox `Frame` badges defined in [src/ui/Icons.lua](../src/ui/Icons.lua). Home uses a filled house, Library uses a script document, Modules uses a command panel, and UI Settings uses three solid slider controls. There are no SVG files, icon fonts, image asset IDs, or third-party icon downloads in the navigation.

Script cover art remains optional. Upload a `png`, `jpg`, or `jpeg` cover beside the game's `main.lua` as described in [CATALOG.md](CATALOG.md).
